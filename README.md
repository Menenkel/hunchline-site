# hunchline.online

The Hunchline home page and invite pages, served by GitHub Pages from `main`.

- `index.html`: hunchline.online
- `404.html`: every other address, including `hunchline.online/invite/CODE`
- `review.html`: internal question review page (not linked, not indexed)
- `icon.png`: app icon used by both pages

The source lives in `web/` in the (private) app repository; copy it here to update the site. Only `main` is published, so there is one live version of the site.
