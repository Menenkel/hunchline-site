# hunchline.online

The Hunchline home page, invite pages and legal pages, served by GitHub Pages from `main`.

- `index.html`: hunchline.online
- `404.html`: every other address, including `hunchline.online/invite/CODE`
- `impressum/`, `privacy/`, `support/`: legal and help pages (linked in every footer)
- `review.html`: internal question review page (not linked, not indexed)
- `fonts/`, `icon.png`: self-hosted fonts and the app icon

This repository is the only copy of the site: edit it here. Only `main` is published, so there is one live version of the site.
